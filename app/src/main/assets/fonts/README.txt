Optional bundled font for Unplug's "Space" font option.

1. On your build computer, download "Space Grotesk" from Google Fonts
   (https://fonts.google.com/specimen/Space+Grotesk — free, SIL Open Font License).
2. Copy the variable font file into this folder and rename it to exactly:

       SpaceGrotesk.ttf

3. Rebuild. "Space" now appears under Launcher settings → Appearance → Font.

Without the file, the option is simply hidden. The font ships inside the app,
so Unplug stays fully offline.
